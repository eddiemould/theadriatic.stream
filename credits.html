Info + Credits


Why 'The Adriatic'? The name came from a mix of: mishearing the lyrics to Asiatic Fever by Godiego, and liking the Adriatic Sea and its setting inspiration for the Ghibli film Porco Rosso. Plus, it's a nice word. I started this project for all the people who ever asked me to play music and as a home for collaborative music programming. People over algorithms.


You can control playback on The Adriatic with the following keyboard shortcuts: 'space' [play & pause], 'm' [mute & unmute].


The site uses the following fonts: iA Writer Quattro for the body (a modified version of IBM Plex made for the writing app I use), Terminal Grotesque for headings and details (both standard and open), and Kyrios for the offline message. It was written in HTML, CSS and JS using VS Studio Code. The code is hosted on Github Pages - you can view it here! The design was mostly inspired by altalenae.


The image is from a Calvin & Hobbes '1812 Overture' strip. The favicon is an old Windows icon from Cakewalk Virtual Jukebox.


The Adriatic is powered by Azuracast.
